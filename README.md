# OK 曲線衝浪：我的校園一天
點按直接開始遊戲：https://prkunnn.github.io/sel/
> 乘著情緒的波浪，找到自己的復原力！

給國小四到六年級學生的社會情緒學習（SEL）網頁遊戲。玩家在一條代表「情緒激發程度」的 OK 曲線上衝浪，經歷校園一天的六個事件，練習辨識情緒、覺察身體訊號、使用調節技能，最後得到自己的「OK 曲線」學習成果卡。

- 類型：2D 橫向衝浪 ＋ 校園互動故事 ＋ 情緒調節小遊戲
- 時間：每個故事約 7–10 分鐘，一次玩一個故事即可
- 平台：電腦、平板、手機瀏覽器（滑鼠、鍵盤、觸控皆可）
- 技術：純 HTML5 / CSS3 / JavaScript ＋ Canvas ＋ Web Audio API
- 不需安裝、不需登入、不需 API Key、不蒐集任何個人資料

## 遊戲內容

### 核心玩法
| 畫面區域 | 顏色 | 意義 |
|---|---|---|
| 高激發區 | 紅橘 | 興奮、期待、緊張、生氣……能量很多（不等於壞情緒） |
| 復原力區 OK Zone | 綠 | 還能思考、學習、互動與應對 |
| 低激發區 | 藍 | 失落、累、想躲起來……能量變少（不等於失敗） |

- 角色在衝浪板上自動前進，波浪高度＝模擬激發程度，角色跟著浪上下移動、板子依坡度傾斜。
- 走過的浪就是玩家自己的 OK 曲線（海水也依三個區域上色）。
- **操作**：空白鍵／↑／點畫面＝跳躍收集光點；← →＝平衡；數字鍵 1–9 選選項；Enter 確認；Esc 暫停。
- 操作失敗不會影響情緒、不會扣分。

### 每個事件的流程
對話 →（衝浪挑戰）→ 情緒辨識（含「其他感受」）→ 身體訊號（可複選）→ 波浪變化 → 情緒精靈回應 → 調節技能（可選）→ 自評有沒有幫助 → 行動選擇 → 角色回應

「情緒」與「激發程度」分開處理：每種情緒有自己的感受方向（愉快／不舒服／中性）與模擬激發程度，再加上身體訊號與少量隨機變化，所以同一個故事重玩會有不同曲線。

### 三個完整故事（各六個事件）
| 故事 | 事件 | 衝浪挑戰 |
|---|---|---|
| 運動會的一天 | 早上到校 → 接力賽即將開始 → 接力賽正式開始 → 接棒失誤 → 同學的不同反應 → 運動會結束 | 接力節奏衝浪（跟拍點） |
| 考試的一天 | 早上準備考試 → 同學討論考試範圍 → 考試開始 → 遇到不會的難題 → 考試結束 → 放學回顧 | 專注平衡衝浪（← → 保持平衡） |
| 校外教學的一天 | 搭車出發 → 抵達參觀地點 → 小組意見不合 → 與隊伍暫時走散 → 重新與隊伍會合 → 返校回顧 | 探索發現衝浪（跳躍收集） |

「與隊伍暫時走散」示範安全做法：留在明顯地點、找穿制服掛識別證的工作人員或服務台、說出學校與老師名字；選「自己到處跑」會得到溫和提醒並重新選擇。

### 四種調節技能小遊戲
| 技能 | 操作 |
|---|---|
| 呼吸光圈 | 光圈變大時按住（空白鍵或按鈕）吸氣、變小時放開吐氣，完成三次；有「較慢節奏」與跳過 |
| 安全港停靠 | 按住煞車讓衝浪板減速停進港口（太快會輕輕彈開再試），再選身體部位與休息方式 |
| 支持浮島 | 選支持者，逐段組出「打招呼＋說出狀況與感受＋說出需要的幫忙」的求助句；不清楚或不尊重的說法會得到提示 |
| 想法拼圖 | 把過度概括的想法拼成「說出事實＋不過度概括＋我可以做的」；否認感受或更絕對的拼圖片會被溫和退回 |

### 結果畫面「我的 OK 曲線」
今日故事、完整平滑曲線、六個事件節點（標示情緒）、每個事件紀錄（情緒、身體訊號、模擬激發程度、技能、自評、挑戰、行動）、用過的技能、個人復原力工具卡、鼓勵性回饋、可下載 PNG 學習成果卡、重新遊玩、返回故事選單。**不以情緒高低或是否待在綠色區評分。**

## 設計原則（SEL）
- 高激發不等於壞情緒；低激發不等於失敗；復原力不是一直開心。
- 不要求玩家否認感受或強迫正向思考；每種感受都會先被接納。
- 不同學生對同一件事可以有不同感受，選項沒有標準答案。
- 情緒數值只用於遊戲模擬，不測量、也不宣稱代表玩家的真實心理狀態。

## 授權
所有程式、美術（SVG／Canvas 向量繪製）與音效（Web Audio 即時合成）皆為本專案原創，沒有使用任何外部圖片或音檔。
